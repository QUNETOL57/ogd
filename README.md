# Mi Fitness · Open Gym

Многопользовательская аналитика Mi Fitness с PostgreSQL, закрытой регистрацией по приглашениям и Docker Compose для Dokploy.

## Возможности

- Импорт зашифрованного ZIP Mi Fitness с паролем; пароль не записывается в БД.
- Метрики шагов, ккал, сон, пульс, стресс и вес с интервалами день / неделя / месяц / год / всё время.
- История тренировок с длительностью, ккал, пульсом, дистанцией и показателями из исходного JSON.
- Open Gym: чтение персональных тренировок по ограниченному API-токену и сопоставление по началу занятия (±30 минут).
- Сравнение только сводных показателей тех пользователей, которые отдельно включили согласие.
- Все даты и время отображаются в Europe/Moscow.

## Развёртывание в Dokploy

1. Скопируйте репозиторий на сервер и создайте `.env` из `.env.example`.
2. Укажите длинный случайный `POSTGRES_PASSWORD`, публичный адрес `APP_ORIGIN` в формате `https://...`, случайный `BOOTSTRAP_INVITE` и сгенерируйте `FERNET_KEY` командой из `.env.example`.
3. В Dokploy создайте приложение из Docker Compose, выберите этот каталог и направьте домен на сервис `app`, порт `8000`.
4. Запустите Compose. PostgreSQL сохраняет данные в volume `postgres_data`; удаление/пересоздание контейнеров БД не удаляет этот volume.
5. Зарегистрируйте первого пользователя с `BOOTSTRAP_INVITE`; он станет администратором. После регистрации удалите `BOOTSTRAP_INVITE` из окружения. Одноразовые приглашения для остальных выдаются в разделе «Настройки».
6. Откройте «Импорт данных», выберите ZIP и введите его пароль.

Не публикуйте PostgreSQL наружу. Настройте резервное копирование volume/дампы БД в Dokploy. Для восстановления нужны также значения `FERNET_KEY` (доступ к сохранённым Open Gym токенам) и `APP_ORIGIN`.

## Open Gym

В Open Gym создайте персональный API-токен с областью `workouts: view`, затем подключите его в настройках дашборда. Токен хранится только в зашифрованном виде через `FERNET_KEY`; синхронизация запрашивает `/api/token/data`. Токен остаётся персональным и не даёт дашборду видеть чужие профили.

## Локальная проверка

```sh
cp .env.example .env
# задайте значения в .env, затем запустите локальную конфигурацию:
docker compose -f docker-compose.yml -f docker-compose.local.yml --env-file .env up --build
```

Откройте `http://localhost:8000`. Локальное переопределение публикует порт только на loopback; основной Compose для Dokploy не публикует приложение напрямую.

Проверка парсера архива без Docker:

```sh
python -m unittest discover -s tests
```

## Ограничения первой версии

- Частота сердечных сокращений и стресс в общем графике агрегируются по дням; детальные временные ряды отображаются в исходных показателях конкретной тренировки.
- Сопоставление Open Gym выбирает ближайшую тренировку с началом в пределах 30 минут. Сопоставление можно улучшить вручную после проверки реальных сценариев.
- Данные Open Gym и Xiaomi доступны только владельцу аккаунта; согласие на сравнение раскрывает другим участникам только агрегаты, не историю и не отдельные показатели здоровья.
